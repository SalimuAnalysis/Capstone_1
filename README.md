# Capstone_1
Business Analysis with SQL and Excel

## Project Description
This project focuses on analyzing sales data for EmporiUm, a fictional retail business that sells books, technology products, art supplies, and other merchandise. Using MySQL and Microsoft Excel, I will analyze sales performance within an assigned sales territory to identify revenue trends, transaction patterns, and opportunities for business growth.
The goal is to use data to provide meaningful insights and recommendations that can help management make informed business decisions.
## Sales Territory
Texas
## Tools Used
MySQL Workbench
Microsoft Excel
GitHub
## Project Objectives
Analyze total sales revenue and monthly sales trends.
Compare sales performance across territories and regions.
Examine transaction activity and product categories.
Create an Excel PivotChart to visualize findings.
Provide data-driven recommendations for improving sales performance.

## Key Findings
- Beaumont was the leading Texas store in total sales revenue.
- Dallas showed a decline in annual sales performance, indicating an opportunity for improvement.
- SQL analysis helped compare revenue, transaction activity, and sales trends across Texas stores.
- Excel PivotCharts helped to visualize and compare sales performance.
## Business Recommendations
1. Investigate the decline in Dallas sales to identify possible causes.
2. Review Beaumont's performance to identify successful practices that could benefit other stores.
3. Monitor monthly sales and adjust inventory based on customer demand.
4. Track revenue, transaction volume, and average sale value to support business decisions.
## Project Files
- `salimu_sales_analysis.sql` - SQL queries used for sales analysis.
- `Salimu_territory_chart.xlsx` - Excel sales visualization.
- `Texas_Store_Rankings.csv` - Texas store sales ranking data.

A presentation summarizing the findings, visualizations, and business recommendations will accompany this analysis.
