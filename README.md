# Capstone_1
Business Analysis with SQL and Excel

## Project Description
This project focuses on analyzing sales data for EmporiUm, a fictional retail business that sells books, technology products, art supplies, and other merchandise. Using MySQL and Microsoft Excel, I will analyze sales performance within an assigned sales territory to identify revenue trends, transaction patterns, and opportunities for business growth.
The goal is to use data to provide meaningful insights and recommendations that can help management make informed business decisions.
